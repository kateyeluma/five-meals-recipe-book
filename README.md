# My Five Meals Recipe Book

## Introduction
This project is a simple recipe book website
that contains five different meals and their
preparation procedures.

## Recipes Included
1. Jollof Rice
2. Fried Rice
3. Eru and Garri
4. Beans and Plantain
5. Chicken Stew

## Features
- Ingredients for each meal
- Preparation time
- Cooking time
- Equipment needed
- Step-by-step cooking procedures
- Serving suggestions

## Technologies Used
- HTML
- CSS

## Project Purpose
This project was created to demonstrate
basic web development skills.
